# SwiftUI Payment UI

واجهة دفع متكاملة باستخدام SwiftUI، تركز على تجربة المستخدم (UX) والتحقق من البيانات المدخلة بشكل فوري.

## المميزات التقنية
* **Input Validation:** الحقول مبرمجة تقبل فقط حروف إنجليزية للأرقام والأسماء لمنع أخطاء الدفع.
* **Auto-Formatting:** تنسيق تلقائي لتاريخ الانتهاء (MM/YY) أثناء الكتابة.
* **Security Constraints:** تحديد عدد الخانات لرقم البطاقة (16) ورمز الـ CVC (3).
* **Apple Pay Simulation:** واجهة مخصصة (Custom Sheet) تحاكي نافذة Apple Pay الأصلية عند الضغط على الزر.

## المتطلبات
* iOS 15.0+
* Xcode 13+
* ملفات الصور (mada, visa, mastercard) في مجلد الـ Assets.

## طريقة الاستخدام
الملف الأساسي هو `PaymentView.swift` يحتوي على الواجهة ومنطق التحقق (Validation Logic)، ويمكن دمجه مباشرة في أي مشروع iOS.
